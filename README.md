# MCP_LAB — ЛР «Политика доступа браузерного MCP-агента»

Учебный комплект по дисциплине «Проектирование и защита агентных систем
на базе больших языковых моделей»: LLM-агент управляет настоящими
веб-страницами через MCP-сервер (JSON-RPC 2.0 по stdio) + Playwright,
а студент учится ограничивать его полномочия программной политикой.

## Куда смотреть

- **Студенческий пакет — `MCP_LAB_STUDENT/`**: код, инструкция, теория,
  атак-страницы. Начните с [`MCP_LAB_STUDENT/README.md`](MCP_LAB_STUDENT/README.md).
- **Готовые PDF — `MCP_LAB_STUDENT/docs/pdf/`**:
  [Инструкция_Wikipedia.pdf](MCP_LAB_STUDENT/docs/pdf/Инструкция_Wikipedia.pdf),
  [Методичка_ЛР_MCP_теория.pdf](MCP_LAB_STUDENT/docs/pdf/Методичка_ЛР_MCP_теория.pdf),
  [Установка_и_удаление_ЛР_MCP.pdf](MCP_LAB_STUDENT/docs/pdf/Установка_и_удаление_ЛР_MCP.pdf),
  [Инструкция_GoogleDrive.pdf](MCP_LAB_STUDENT/docs/pdf/Инструкция_GoogleDrive.pdf).
- **Drive-PDF — только для просмотра**: `Инструкция_GoogleDrive.pdf`
  — эталонная демонстрация преподавателя (семантические `drive_*`-
  инструменты есть только в эталонном комплекте; в студенческой сборке
  их нет — Drive-упражнение и код студенту не выдаются).

## Состав репозитория

- `MCP_LAB_STUDENT/` — то, что получают студенты.
- `MCP_LAB/` — эталонный комплект преподавателя (решения, инструменты
  Drive, генераторы документов); в публичную выдачу не входит.
- `out_pdf/` — рабочие копии сгенерированных PDF преподавателя.
