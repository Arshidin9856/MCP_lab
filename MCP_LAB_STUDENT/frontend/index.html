Browser Agent

LLM-агент управляет реальным сайтом через MCP-инструменты (JSON-RPC → Playwright)

Как это устроено

📊 диаграмма пути прогона — откроется в новой вкладке

  1. server.py — MCP-сервер (stdio, JSON-RPC 2.0): владеет сессией Chrome и отдаёт инструменты browser_navigate / snapshot / click / type / press / scroll / back
  2. agent.py — хост: запрашивает tools/list, гоняет цикл снапшот → LLM → проверки → tools/call → верификация; держит scope и журнал
  3. Модель видит структурированный снапшот страницы (refs e0,e1,…), без скриншотов и сырого HTML
  4. task_done — хост-инструмент: модель завершает задачу с ответом; на сервер этот вызов не уходит
  5. Вставьте ссылку в первое сообщение — агент сам откроет страницу, а scope ограничится её доменом
